# Beecrowd Solutions (Java)

Repositório dedicado à resolução de problemas da plataforma **Beecrowd** utilizando a linguagem **Java**. O objetivo principal é o aprimoramento em lógica de programação e algoritmos.

---

## 🛠️ Tecnologias e Ferramentas

* **Linguagem:** Java (JDK 17 ou superior)
* **IDE:** IntelliJ IDEA
* **Plataforma:** [Beecrowd](https://www.beecrowd.com.br/)
* Git/GitHub

---

## 📂 Estrutura do Projeto

Os problemas estão organizados por categoria dentro da pasta `src`:
* **src/Iniciante:** Desafios de nível básico.
